KIBLATKU - PROYEK ANDROID SIAP BUILD
====================================
Proyek ini berisi index.html Anda (di app/src/main/assets/), kode MainActivity.kt
dan izin GPS dari paket asli, ditambah konfigurasi Gradle dan ikon aplikasi.

CARA A - BUILD OTOMATIS DI GITHUB (tanpa Android Studio)
--------------------------------------------------------
1. Buat akun & repositori baru di github.com (boleh private).
2. Upload SELURUH isi folder proyek ini (termasuk folder .github).
   Di browser: "Add file" -> "Upload files". Jika folder .github tidak ikut
   terunggah lewat drag-drop, buat manual: "Add file" -> "Create new file",
   ketik  .github/workflows/build-apk.yml  lalu tempel isi file tersebut.
3. Buka tab "Actions". Build jalan otomatis (sekitar 3-6 menit).
   Jika tidak, pilih "Build APK KiblatKu" -> "Run workflow".
4. Setelah centang hijau, buka run tersebut, lalu unduh "KiblatKu-APK"
   di bagian Artifacts. Ekstrak ZIP-nya -> app-debug.apk.
5. Pindahkan ke HP, buka, izinkan "Install dari sumber tidak dikenal".

CARA B - ANDROID STUDIO
-----------------------
1. File -> Open -> pilih folder proyek ini, tunggu Gradle sync selesai.
2. Build -> Build Bundle(s) / APK(s) -> Build APK(s).
3. APK ada di app/build/outputs/apk/debug/app-debug.apk

CATATAN
-------
- APK yang dihasilkan adalah APK debug: bisa langsung dipasang di HP, tetapi
  belum bisa diunggah ke Google Play. Untuk Play Store butuh APK/AAB release
  yang ditandatangani dengan keystore Anda sendiri.
- Ubah versi di app/build.gradle (versionCode / versionName) saat memperbarui.
- Jika ingin mengubah tampilan, edit app/src/main/assets/index.html lalu build ulang.
